# Corpus

| Tier | Location | What it is | Trust | Good for |
|---|---|---|---|---|
| Synthetic | `samples/synthetic/` | Generated by `MakeSample.java`; cached values written by hand, **not computed by Excel** | **Lower-trust: never fidelity ground truth** | Reader tests, CLI demo |
| POI samples | `samples/poi/` | A few files copied from the tier below | Per the writer label; see `samples/poi/README.md` | Tests that need real files without a download |
| POI test data | `downloads/poi/` (not committed) | `.xlsx` files from Apache POI's test data, pinned by commit and SHA-256 in `manifest.tsv` | Mixed: many claim Excel as writer, others were written by libraries or are deliberately corrupt | Reader robustness |

**POI test data is not representative of real-world models.** It consists largely of bug reproductions
and fuzzer output, so function rankings from it must not be described as real-world usage. A real-world
corpus is an open decision: see ADR-0008.

## Commands

```
corpus/download.sh            # fetch and verify everything in manifest.tsv
corpus/pin-poi.sh <commit>    # move the pin and regenerate manifest.tsv
java corpus/samples/synthetic/MakeSample.java corpus/samples/synthetic/sample.xlsx
```

## Licensing

Individual test files came from bug reports, so provenance varies, which is why the full set is
downloaded from upstream rather than redistributed here. The manifest names the license and source of
every file.
